# Chess React + TypeScript (Pet Project)

Это pet-проект, который я делаю для практики **React + TypeScript**.

## Цель проекта

- закрепить синтаксис TypeScript на реальном приложении;
- научиться работать со state и рендером в React;
- реализовать игровую логику с типами и проверками правил.

## Что используется

- React 19
- TypeScript
- Vite
- CSS
- Docker + Docker Compose
- Nginx (для production-сборки)

## Что реализовано

- шахматная доска 8x8;
- стартовая расстановка фигур;
- ходы всех фигур по правилам;
- проверка легальности ходов (нельзя оставить короля под шахом);
- шах, мат, пат;
- рокировка;
- взятие на проходе;
- промоция пешки с выбором фигуры;
- перезапуск партии (`New Game`).

## Краткий принцип работы

1. Доска хранится как `Board = BoardCell[][]`.
2. Для выбранной фигуры генерируются псевдолегальные ходы.
3. Каждый ход проверяется симуляцией: если после хода король под шахом, ход отбрасывается.
4. При валидном ходе обновляются:
   - позиция фигур;
   - очередь хода (`white/black`);
   - права рокировки;
   - цель для взятия на проходе.
5. После каждого хода проверяется состояние партии: обычная игра, шах, мат или пат.

## Запуск локально

```bash
cd frontend
npm install
npm run dev
```

## Запуск в Docker

Из корня проекта:

```bash
docker compose up --build
```

Открыть в браузере: `http://localhost:8080`
